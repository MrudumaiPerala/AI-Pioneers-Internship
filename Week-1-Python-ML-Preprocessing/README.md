# Week 1: Python ML Preprocessing

This module covers the core foundations of Machine Learning data preprocessing and exploratory data analysis.

## Key Topics
- Missing value imputation using median and mode
- Deduplication of records
- Feature selection
- Categorical variable encoding with One-Hot Encoding
- Standard normal feature scaling (Z-score)
- Correlation matrix computation and EDA

## Files
- `preprocessing.ipynb` — Interactive Jupyter notebook for the preprocessing workflow.
- `Week1.py` — Standalone runnable Python preprocessing script.
- `data/sample_dataset.csv` — Raw input dataset with missing values.
- `data/cleaned_dataset.csv` — Cleaned and preprocessed output dataset.
